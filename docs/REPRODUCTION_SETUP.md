Obtain Node and client binaries from their publishers and verify their published checksums/signatures. The console .nvmrc is a selector, not a downloader or authenticity proof.

## Generate new headers and proofs locally

This procedure creates a new database, executes the published signed21-transaction fixture, reads new headers and requests a new storage proof. It does not merely validate saved proof JSON. It deliberately reuses published synthetic genesis and signed transaction inputs; it is not a from-source rebuild/signing of the original fixture.

Verify the client using [client provenance](CLIENT_BINARY_PROVENANCE.md). The capture enforces Geth executable SHA-256 `45335929e149413c9f680209c87fa14adc5750387da6f5f30b7b2bd24d2d54ea`. Use only disposable local data, with2GiB free disk and1GiB available memory. Output parent must exist and the selected output must not exist.

```sh
python3 integration/core-baseline-v1/capture-public-wallet.py --geth /absolute/path/to/verified/geth --capture evidence/wallet-headers-20261112/capture.json --genesis evidence/wallet-headers-20261112/genesis.json --expected evidence/wallet-headers-20261112/expected-storage.json --output /absolute/path/to/new-wallet-capture
node integration/core-baseline-v1/verify-fresh-wallet.mjs /absolute/path/to/new-wallet-capture/evidence.json evidence/wallet-headers-20261112/expected-storage.json
```

The capture requires the selected genesis, signed transaction identities, receipt statuses, all21 state roots and contiguous parent hashes to match their declared inputs. It saves new capture/evidence/result/service/provenance records and stops its owned node. The reader uses the same strict proof library and expected values as the fixed capture, with the new local endpoint selected explicitly. New timestamps can change header hashes; do not edit the original fixed-header verifier or expected record to make a new run pass. The local endpoint is not a consensus-authenticated public anchor.

Observed:21/21 execution state roots matched; all16 registry fields and five corruption controls passed; service stopped. These are same-operator results. Independent operation, complete source-to-fixture generation and source-to-client-binary builds remain unproven.
